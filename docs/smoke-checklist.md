# LightNote Smoke Checklist

本文档用于正式发版或大改动后做手工验收。

## 服务端

- [ ] VPS 上执行 `docker compose ps`，`lightnote-server` 和 `lightnote-mysql` 均为运行状态。
- [ ] `curl http://127.0.0.1:8080/api/health` 返回 `status: UP`。
- [ ] 外部访问 `http://203.0.113.10:8080/api/health` 正常。
- [ ] 服务端日志没有持续重启或数据库连接失败。

## 客户端启动

- [ ] `pwsh .\scripts\start-client.ps1` 能启动开发版客户端。
- [ ] `pwsh .\scripts\package-client.ps1` 能生成便携包。
- [ ] 便携包 `LightNote.cmd` 能启动客户端。
- [ ] 登录页能填写服务端地址并完成登录。

## 笔记基础功能

- [ ] 新建笔记。
- [ ] 编辑标题和正文。
- [ ] 自动保存后重启客户端，内容仍存在。
- [ ] 收藏、置顶、归档状态能正确显示。
- [ ] 删除笔记后进入回收站。
- [ ] 回收站中可以恢复笔记。
- [ ] 回收站中可以彻底删除笔记。

## 分类和搜索

- [ ] 新建分类。
- [ ] 修改笔记分类。
- [ ] 左侧分类计数正确。
- [ ] 重命名空分类和非空分类行为符合预期。
- [ ] 删除空分类。
- [ ] 搜索标题命中有高亮。
- [ ] 搜索正文摘要命中有高亮。
- [ ] 清空搜索后列表恢复。

## Markdown

- [ ] Markdown 编辑模式可输入。
- [ ] 预览模式可渲染标题、列表、代码块、引用和链接。
- [ ] 分屏模式显示正常。
- [ ] HTML 旧笔记可打开。
- [ ] 单篇 HTML 笔记转换 Markdown 前有确认。

## 同步

- [ ] 手动同步成功。
- [ ] 自动同步不会打断正在编辑的正文。
- [ ] 同步失败时本地保存不受影响。
- [ ] 登录过期后手动同步会触发重新登录。
- [ ] 冲突时生成冲突副本。
- [ ] 当前编辑笔记发生冲突时自动切到冲突副本。

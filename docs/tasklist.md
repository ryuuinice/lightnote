# LightNote 后续工作 Tasklist

更新时间：2026-05-11

## 目标

下一阶段以“稳定同步体验、打磨笔记编辑体验、补齐产品化能力”为主。当前版本已经具备登录、本地保存、云端同步、自动同步、富文本编辑和基础笔记管理能力；后续工作重点从“能用”转向“好用、稳定、像产品”。

## P0：同步稳定性验证

- [x] 连续输入时自动同步不丢内容
- [x] 自动同步后当前笔记不丢选择
- [x] 自动同步时不重载正在编辑的正文
- [x] 同步失败后状态灯保持红色
- [x] 网络异常或服务端异常时不影响本地保存
- [x] 同步过程中继续编辑时，当前同步结束后能继续排下一次同步
- [x] 手动同步和自动同步同时触发时不会并发写入
- [ ] 做一轮真实交互 smoke，补最终确认

## P1：同步状态体验优化

- [x] 状态灯加 tooltip
  - 绿色：已同步
  - 黄色：同步中
  - 红色：未同步、同步失败或有冲突
- [x] 底部弱提示精简，避免反复出现“自动同步完成”干扰写作
- [x] 手动同步按钮点击后给轻反馈
- [x] 同步失败提示保留最后一次错误原因
- [x] 冲突状态给明确入口，而不是只显示红灯
- [x] 本地保存失败和远端同步失败分开提示
- [x] 当前编辑笔记发生冲突时自动切到冲突副本继续编辑

## P1：编辑器体验优化

- [x] 压缩 JavaFX `HTMLEditor` 原生工具条高度
- [ ] 梳理常用格式能力
  - 字号
  - 字体
  - 加粗
  - 斜体
  - 下划线
  - 删除线
  - 文字颜色
  - 高亮
  - 有序列表
  - 无序列表
  - 对齐
- [ ] 优化段落行距、标题样式、正文留白
- [ ] 检查富文本保存后再次打开的格式一致性
  - 进行中：已增加存储前 HTML 清洗，去除编辑器样式和常见粘贴残留
- [ ] 检查复制粘贴富文本后的格式表现
  - 进行中：已增加 `StartFragment/meta/script/o:p` 等常见粘贴残留清洗
- [ ] 评估后续是否替换 JavaFX `HTMLEditor` 为更可控的编辑内核

## 当前优先建议

当前优先建议先补两块：

1. 完成 P0 的真实交互 smoke，重点验证“持续输入 + 自动同步 + 冲突切换副本”整条链路。
2. 继续做 P1 编辑器体验优化，优先压缩 `HTMLEditor` 工具条、整理高频格式能力。

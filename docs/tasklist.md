# LightNote 后续工作 Tasklist

更新时间：2026-05-08

## 目标

下一阶段以“稳定同步体验、打磨笔记编辑体验、补齐产品化能力”为主。当前版本已经具备登录、本地保存、云端同步、自动同步、富文本编辑和基础笔记管理能力；后续工作重点从“能用”转向“好用、稳定、像产品”。

## P0：同步稳定性验证

- [ ] 连续输入时自动同步不丢内容
- [ ] 自动同步后当前笔记不丢选择
- [ ] 自动同步时不重载正在编辑的正文
- [ ] 同步失败后状态灯保持红色
- [ ] 网络异常或服务端异常时不影响本地保存
- [ ] 同步过程中继续编辑时，当前同步结束后能继续排下一次同步
- [ ] 手动同步和自动同步同时触发时不会并发写入

## P1：同步状态体验优化

- [ ] 状态灯加 tooltip
  - 绿色：已同步
  - 黄色：同步中
  - 红色：未同步、同步失败或有冲突
- [ ] 底部弱提示精简，避免反复出现“自动同步完成”干扰写作
- [ ] 手动同步按钮点击后给轻反馈
- [ ] 同步失败提示保留最后一次错误原因
- [ ] 冲突状态给明确入口，而不是只显示红灯

## P1：编辑器体验优化

- [ ] 压缩 JavaFX `HTMLEditor` 原生工具条高度
- [ ] 梳理常用格式能力
  - 字号
  - 字体
  - 加粗
  - 斜体
  - 下划线
  - 删除线
  - 文字颜色
  - 高亮
  - 有序列表
  - 无序列表
  - 对齐
- [ ] 优化段落行距、标题样式、正文留白
- [ ] 检查富文本保存后再次打开的格式一致性
- [ ] 检查复制粘贴富文本后的格式表现
- [ ] 评估后续是否替换 JavaFX `HTMLEditor` 为更可控的编辑内核

## P1：主界面视觉细节打磨

- [ ] 统一滚动条、复选框、下拉框、颜色选择器样式
- [ ] 优化左侧导航选中态
- [ ] 优化笔记列表 hover 状态
- [ ] 优化笔记列表 selected 状态
- [ ] 检查浅色标题栏在 Windows 下的表现
- [ ] 检查不同窗口尺寸下的布局稳定性
- [ ] 减少编辑区、列表区、导航区之间的割裂感

## P2：笔记组织能力

- [ ] 分类从输入框升级为可选、可管理
- [ ] 左侧分类列表显示真实分类
- [ ] 支持新建分类
- [ ] 支持重命名分类
- [ ] 支持删除空分类
- [ ] 收藏、归档、最近等入口展示数量
- [ ] 后续支持标签

## P2：搜索体验

- [ ] 搜索结果高亮
- [ ] 搜索范围覆盖标题、摘要、正文纯文本
- [ ] 搜索时不打断当前编辑
- [ ] 空结果状态优化
- [ ] 搜索框支持清空按钮
- [ ] 搜索结果保留当前筛选上下文

## P2：安全和数据可靠性

- [ ] 本地保存失败时明确提示
- [ ] 同步冲突入口优化
- [ ] 冲突副本命名和展示优化
- [ ] 增加本地数据库初始化日志
- [ ] 增加本地数据库迁移日志
- [ ] 检查数据库路径兜底策略
- [ ] 检查服务端连接失败时的降级体验

## P3：验证和打包

- [ ] 做一轮手工 smoke test
- [ ] 补最小单元测试
- [ ] 补同步集成测试
- [ ] 完善启动脚本
- [ ] 增加客户端运行日志
- [ ] 生成 Windows 可执行包
- [ ] 生成 Windows 安装包

## 建议执行顺序

1. P0 同步稳定性验证
2. P1 同步状态体验优化
3. P1 编辑器体验优化
4. P1 主界面视觉细节打磨
5. P2 笔记组织能力
6. P2 搜索体验
7. P2 安全和数据可靠性
8. P3 验证和打包

## 当前优先建议

下一步建议先做 P0 和 P1 的前半部分，尤其是自动同步场景。同步是云笔记产品的核心信任基础，必须先保证持续编辑、自动保存、自动同步三者之间不会互相覆盖或打断。
